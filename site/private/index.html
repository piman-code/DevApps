    공개 페이지 앱 목록 열기

    비밀키 바꾸기

    키는 Cloudflare 비밀 변수에만 있습니다. 바꾸면 기존 쿠키는 자동으로 무효가 됩니다. 다운로드 키를 바꾸면 선생님들께 새 키를 안내해야 합니다.

    # 공개용 다운로드 키
npx wrangler pages secret put DOWNLOAD_KEY --project-name piman-devapps

# 이 전용 영역의 관리자 키
npx wrangler pages secret put ADMIN_KEY --project-name piman-devapps
